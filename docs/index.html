Install in 30 seconds

bash
# 1 — install
npm install -g forgecode

# 2 — start your local runtime (one of)
lms server start          # LM Studio
ollama serve              # or Ollama

# 3 — verify
forge doctor
forge models

# 4 — go
forge "refactor src/providers into a registry"
forge --parallel 4 "add tests + docs for the new registry"
  1. 1LM Studio: Developer → Local Server → Start. Load a model (Gemma 12B QAT or Qwen3 27B recommended on 16GB). Forge auto-detects via /v1/models + filesystem scan.
  2. 2Ollama: ollama pull qwen2.5-coder:7b. Forge uses /api/tags for metadata.
  3. 3llama.cpp: ./llama-server -m model.gguf --port 8080. Any GGUF works.
  4. 4Hybrid (optional): set OPENAI_API_KEY / ANTHROPIC_API_KEY. Router sends only hard tasks to frontier.
